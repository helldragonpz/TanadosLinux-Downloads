Public installation downloads need no GitHub account. Operating-system source
stays in the private TanadosLinux repository. The generated Source code ZIP
contains this website, not the operating system.

Choose Windows or Linux for Media Creator, according to the computer creating
the USB. **The ISO is the same for both.** Keep the ISO and .sha256 together,
then open the ISO in Media Creator. A 16 GB USB is required.

This is a preview. Secure Boot must be off. Physical installation, native Windows
USB writing/joining, dual boot, encryption and complete Recovery boot remain
acceptance steps. Signed desktop preview updates still need private repository
access; public installation downloads and APT system updates do not.

GitHub Pages serves the root of main. Fonts retain their license in
assets/INTER-LICENSE.txt; original generated Tanados wallpapers follow the
wallpaper package's CC-BY-SA-4.0 license. Screenshots depict actual apps and do
not guarantee identical hardware, libraries or installed content.
