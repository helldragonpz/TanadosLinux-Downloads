Публична страница и инсталационни файлове за приятелите ни. Не е нужен GitHub акаунт. Кодът на операционната система остава в частното TanadosLinux repo.

Public download website and installation files for our friends. No GitHub account is required. Operating-system source stays in the private TanadosLinux repository.

- [Ръководство на български](INSTALL.bg.md)
- [English installation guide](INSTALL.md)
- [Release files and checksums](https://github.com/helldragonpz/TanadosLinux-Downloads/releases)
- [Report a problem](https://github.com/helldragonpz/TanadosLinux-Downloads/issues)

Choose Windows or Linux on the download page. Download all four ISO parts and the joining helper, then open the verified ISO in Media Creator. A 16 GB USB is required. The generated Source code ZIP/tarball contains this website, not the operating system.

This is a preview. Secure Boot must be off. Back up the target computer. Physical PC/laptop installation and native Windows USB writing remain acceptance steps. The release notes record the checks completed for each image. Signed desktop preview updates still require access to the private repository; public installation files and APT system updates do not.

The website is published by GitHub Pages from the root of `main`. Fonts include their license in `assets/INTER-LICENSE.txt`; the generated Tanados Aperture artwork follows the wallpaper package's CC-BY-SA-4.0 license.
